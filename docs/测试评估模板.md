## 核心指标

| 指标 | 算法 | 本批汇总 |
|------|------|----------|
| **动作规划正确率** | 评审为「正确」的 case 数 ÷ 评审 case 数 | **21 / 22 = 95.5%**（含 1 ⚠️） |
| **用例执行成功率** | 通过 case 数 ÷ 执行 case 数 | **18 / 22 = 81.8%** |
| **步骤执行成功率** | 通过步骤数 ÷ 总步骤数 | **212 / 227 = 93.4%** |

**规划评审**：✅ 正确 / ⚠️ 有小问题可修 / ❌ 错误（漏步骤、错类型、缺断言等）

**执行失败归因**：规划问题 / 定位 / 后校验 / 环境数据

> 规划错了导致跑挂，记规划问题，别全算执行能力差。
